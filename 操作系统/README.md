# 操作系统

底层运行环境 — 宿主机 + 虚拟化层 + Linux 发行版。

| 层级 | 工具 | 说明 |
|------|------|------|
| 🪟 宿主机 | **Windows** | 基础操作系统，运行 GUI 应用和浏览器 |
| ⚡ 虚拟化层 | **WSL 2** | Windows Subsystem for Linux 2 — 完整的 Linux 内核，性能接近原生 |
| 🐧 Linux 环境 | **openSUSE Tumbleweed** | 滚动发行版 Linux，始终保持最新软件包，适合开发环境 |

## 架构

```
┌─ Windows（宿主机）─────────────┐
│  GUI 应用 / 浏览器 / 编辑器     │
│           │                     │
│  ┌─ WSL 2（虚拟化层）⚡ ──────┐ │
│  │  完整的 Linux 内核          │ │
│  │           │                 │ │
│  │  openSUSE Tumbleweed       │ │
│  │  Node.js / Python / Git    │ │
│  └────────────────────────────┘ │
└─────────────────────────────────┘
```

## 为什么选这套组合

- **WSL 2** 提供完整的 Linux 内核，无需双系统或虚拟机即可在 Windows 上运行 Linux
- **openSUSE Tumbleweed** 滚动更新，工具链始终保持最新版本
- Windows 作为宿主机，保留 GUI 应用（浏览器、编辑器等）的原生体验

## ⌨️ 输入法

| 组件 | 说明 |
|------|------|
| 🐿️ **[Squirrel（鼠须管）](https://github.com/rime/squirrel)** | Rime 输入法引擎的 macOS 前端，轻量、快速、高度可定制 |
| 🌐 **[万象](https://github.com/amzxyz/RIME-LMDG)** | Rime 拼音输入方案，支持全拼/双拼，词库精准，持续维护 |

### 为什么选这套方案

- **Rime 引擎**：开源、离线、跨平台，不依赖云端词库，隐私友好
- **万象方案**：词库质量高，繁简转换准确，支持多种双拼布局
- **高度可定制**：YAML 配置文件完全可控，可按需调整候选词、符号、快捷键等
