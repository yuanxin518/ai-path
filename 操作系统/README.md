# 操作系统

底层运行环境。

| 工具 | 说明 |
|------|------|
| **WSL 2** | Windows Subsystem for Linux 2 — Windows 下的 Linux 运行环境，性能接近原生 |
| **openSUSE Tumbleweed** | 滚动发行版 Linux，始终最新内核和软件包，适合开发环境 |

## 为什么选这套组合

- **WSL 2** 提供完整的 Linux 内核，无需双系统或虚拟机即可在 Windows 上运行 Linux
- **openSUSE Tumbleweed** 滚动更新，工具链始终保持最新版本
- 开发工具（Node.js、Python、Git 等）在 Tumbleweed 上开箱即用
