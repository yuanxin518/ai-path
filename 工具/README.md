# 工具

通过 MCP 协议让 AI 操作外部系统和服务。

---

## chrome-devtools-mcp

Chrome 官方出品的 MCP 服务，让 AI 编程助手控制浏览器，支持 DevTools 检查、调试、修改页面内容。

- [GitHub](https://github.com/ChromeDevTools/chrome-devtools-mcp)

---

## opencli

把任何网站变成 CLI 工具，零配置，AI 驱动。支持 153 个站点适配器、9 个 App 适配器、13 个外部 CLI，以及浏览器操控能力。

- 安装：`npm install -g @jackwener/opencli`
- 版本：1.8.3
- 基本用法：`opencli <site> <command> [options]`
- 查看站点命令：`opencli <site> --help`
- 浏览器操控：`opencli browser open/screenshot/click/fill/extract`
- [GitHub](https://github.com/jackwener/opencli)
