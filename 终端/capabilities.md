# 终端能力

DeepSeek Harness（dsh）自带以下能力，无需额外安装：

| 能力 | 说明 |
|------|------|
| Agent 会话 | 多步任务自动执行，支持计划模式 |
| 插件架构 | 一切皆插件（everything-is-a-plugin），基于 Cordis |
| Web UI | `npx @deepseek-ai/dsh web` 启动本地 Web 界面（127.0.0.1:3080） |
| MCP 集成 | 通过 MCP 协议调用外部服务 |
| 技能系统 | 加载可复用的技能包（skills） |
| 多代理协作 | 组建 Agent 团队，并行分发子任务 |
| Shell 执行 | 在会话中直接运行命令 |
