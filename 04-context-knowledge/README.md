# 04 — 上下文与知识管理

**做什么**：AI 能知道什么，取决于你喂了什么。这个节点管理怎么给 AI 提供上下文。

**位置**：工具扩展层之上。工具让 AI 能做事，上下文让 AI 做对事。

---

## 能力分支

### 项目上下文

每个工作目录下的指令文件，告诉 AI 这个项目的规则。

| 文件 | 平台 | 用途 |
|------|------|------|
| `AGENTS.md` | DeepSeek TUI | 项目级指令，自动加载 |
| `CLAUDE.md` | Claude Code | 项目级指令，自动加载 |
| `.trellis/` | Trellis 管理项目 | 规格、工作流、任务管理 |

> 实践：在项目根目录放一份 `AGENTS.md` / `CLAUDE.md`，描述项目结构、编码规范、
> 关键约定。每次对话 AI 会自动读取。

### RLM（长上下文处理）

Recursive LM — 持久化 Python REPL 会话，用于大文件分析、批量分类、语义搜索。

| 平台 | 能力 | 状态 |
|------|------|------|
| DeepSeek TUI RLM | 1M token 上下文，子查询、批量处理 | ✅ 在用 |

> 场景：日志分析（几十万行）、项目代码普查、跨文件语义搜索。

### Memory — 持久化记忆

AI 跨会话记住你的偏好和工作状态。

| 类型 | 位置 | 状态 |
|------|------|------|
| DeepSeek Memory | `~/.deepseek/memory.md` | ✅ 在用 |
| Claude Projects | Claude.ai 项目知识库 | ✅ 在用 |

### RAG（检索增强生成）

海量文档中检索相关片段喂给 AI。

| 工具 | 用途 | 状态 |
|------|------|------|
| MCP + 向量数据库 | 语义搜索文档库 | 📌 待研究 |
| Context Pack | 项目上下文快照 | 📌 待研究 |

---

## 我的上下文策略

```
每个项目
  └── AGENTS.md + .trellis/ → 项目核心规则

每次对话
  └── 当前文件上下文 → AI 自动读入
  └── Memory → 跨会话偏好持久化

大数据分析
  └── RLM 会话 → 日志/代码库批量分析
```
