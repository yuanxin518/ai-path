# 03 — 工具/插件扩展层

**做什么**：AI 能调用什么外部工具来丰富自己的能力边界。

**位置**：Agent 能力的倍增器。没有工具，Agent 只能思考；有了工具，Agent 能执行。

---

## 扩展类型

### [MCP 服务器](./mcp-servers/)

Model Context Protocol — 标准化的 AI 工具协议。

让 AI 能访问文件系统、数据库、Git 仓库、浏览器、API 等外部资源。

- [查看 MCP 服务清单 →](./mcp-servers/)

### [Skills](./skills/)

DeepSeek TUI 的本地指令技能包 — 可复用的能力块。

每个 Skill 封装了一套指令 + 配套文件，一次安装，随处调用。

- [查看 Skills 清单 →](./skills/)

### [Shell 工具](./shell-tools/)

终端命令、脚本、管道集成 — 最灵活也最强大的扩展方式。

- [查看 Shell 工具清单 →](./shell-tools/)

---

## 快速对比

| 扩展类型 | 用途 | 使用方式 | 适用场景 |
|---------|------|---------|---------|
| MCP 服务器 | 访问外部系统/服务 | Agent 自动调用 | 数据库、API、浏览器、文件系统 |
| Skills | 封装指令和知识 | 用户/Agent 显式调用 | 代码审查、技能教学、工作流 |
| Shell 工具 | 执行终端命令 | Agent/用户手动执行 | 开发任务、自动化脚本、系统管理 |
