# Shell 工具

**做什么**：终端命令、脚本、管道 — 最灵活的 AI 扩展方式。

**为什么重要**：在 TUI/CLI 环境下，Shell 是 AI Agent 最强的能力延伸。

---

## 日常工具链

| 工具 | 用途 | 状态 |
|------|------|------|
| `fzf` | 模糊搜索文件/历史 | ✅ 在用 |
| `ripgrep` / `rg` | 超快速代码搜索 | ✅ 在用 |
| `fd` | 快速文件查找 | ✅ 在用 |
| `bat` | 语法高亮文件查看 | ✅ 在用 |
| `eza` | 增强版 `ls` | ✅ 在用 |
| `git` + `gh` | 版本控制 + GitHub CLI | ✅ 在用 |
| `jq` / `yq` | JSON/YAML 处理 | ✅ 在用 |
| `tmux` | 终端会话管理 | ✅ 在用 |
| `fish` | Shell 环境 | ✅ 在用 |
