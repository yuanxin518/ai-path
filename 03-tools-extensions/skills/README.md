# Skills

## 什么是 Skill

Skill 是 DeepSeek TUI 的本地指令技能包，一个 `SKILL.md` 文件 + 可选配套脚本/文件。

> 类比：Skill ≈ 给 AI 的"说明书" — 告诉 AI 某种任务怎么做、用什么工具、注意什么。

## 我安装/使用的 Skills

| Skill | 用途 | 状态 |
|-------|------|------|
| **delegate** | 分批执行子代理任务 | ✅ 在用 |
| **diagnose** | 系统性 Debug 诊断流程 | ✅ 在用 |
| **tdd** | 测试驱动开发（红-绿-重构） | ✅ 在用 |
| **zoom-out** | 从代码细节获取全貌 | ✅ 在用 |
| **to-issues** | 将计划拆为 GitHub Issues | 🔄 偶尔用 |
| **to-prd** | 从对话生成 PRD | 🔄 偶尔用 |
| **triage** | Issue 分类/状态机管理 | 🔄 偶尔用 |
| **grill-me** | 压力测试设计方案 | 🔄 偶尔用 |
| **write-a-skill** | 快速创建新 Skill | 🔄 偶尔用 |
| **mcp-builder** | 构建/调试 MCP 服务器 | 📌 待试用 |
| **feishu** | 飞书集成 | 📌 待试用 |
